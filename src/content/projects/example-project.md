## 这个示例展示什么

这是本地开发用的项目配置模板，没有绑定 GitHub 仓库，不显示 Star 或真实项目链接。

项目与文章可以双向关联。在真实项目中，填写公开的 `repoFullName`，审核后再加入精选列表。

## 正式使用时

写清楚项目解决的问题、公开代码的位置，以及读者可以参考的文章。演示链接只在实际存在时填写。

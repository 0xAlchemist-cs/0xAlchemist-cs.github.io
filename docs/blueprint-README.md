# GitHub Pages × Astro × SEO/GEO 博客开发包

**目的**：用 GitHub 免费域名 `https://<username>.github.io/` 构建技术博客；无需域名、服务器或付费 AI Key。

## 文件说明

| 文件 | 用途 |
|---|---|
| `01_Codex_开发总提示词.md` | 直接复制给 Codex，按阶段开发与验收 |
| `02_产品架构说明.md` | 产品层次、信息流、功能边界、数据模型 |
| `03_开发流程与验收.md` | 分阶段开发、日常发布、故障处理清单 |
| `04_免费部署步骤.md` | 手动创建免费仓库、设置 Pages 的操作卡 |
| `architecture.png` / `.svg` | 完整产品架构图（PNG 预览 / SVG 高清） |
| `development_flow.png` / `.svg` | 开发、上线、内容运营流程图 |
| `architecture.mmd` | 架构图的 Mermaid 可编辑源文件 |
| `development_flow.mmd` | 流程图的 Mermaid 可编辑源文件 |

## 从这里开始

1. 用现有 GitHub 账号确认用户名。
2. 在 Codex 中打开你的本地空目录，发送 `01_Codex_开发总提示词.md` 的全文。
3. 新建公开仓库 `<username>.github.io`；没有确认账号前，Codex 应先保留占位符。
4. 按阶段验收，不要直接让 AI 跳过构建检查、把占位信息当成真实数据或自动购买服务。
5. 上线后填写你的真实文章和公开项目，使用 Search Console 检查实际效果。

**声明**：本包是开发规范、架构设计和流程图，不是已经构建完成的博客源码，不代表已登录你的 GitHub 或已部署。
